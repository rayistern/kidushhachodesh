## Halachot

### 16:2 — node mean motion and period blocks

> מַהֲלַךְ הָרֹאשׁ הָאֶמְצָעִי בְּיוֹם אֶחָד ג' חֲלָקִים וְי"א שְׁנִיּוֹת. נִמְצָא מַהֲלָכוֹ בְּי' יָמִים ל"א חֲלָקִים וּמ"ז שְׁנִיּוֹת. וְנִמְצָא מַהֲלָכוֹ בְּק' יוֹם ה' מַעֲלוֹת וְי"ז חֲלָקִים וּמ"ג שְׁנִיּוֹת. סִימָנָם הי"ז מ"ג. וְנִמְצָא מַהֲלָכוֹ בְּאֶלֶף יוֹם נ"ב מַעֲלוֹת וְנ"ז חֲלָקִים וְי' שְׁנִיּוֹת. סִימָנָם נ"ב נז"י. וְנִמְצָא שְׁאֵרִית מַהֲלָכוֹ בַּעֲשֶׂרֶת אֲלָפִים יוֹם קס"ט מַעֲלוֹת וְל"א חֲלָקִים וּמ' שְׁנִיּוֹת.

### 16:3 — makom harosh = 360 − emtza

> תּוֹצִיא אֶמְצָעָם לְאוֹתוֹ הָעֵת... וְתִגְרַע הָאֶמְצַע מִש"ס מַעֲלוֹת. וְהַנִּשְׁאָר הוּא מְקוֹם הָרֹאשׁ בְּאוֹתָהּ הָעֵת. וּכְנֶגְדּוֹ לְעוֹלָם יִהְיֶה מְקוֹם הַזָּנָב:

→ The node position is **360° minus** the accumulated mean motion. (The
animation fast-path in `liveLongitudes.js` historically used
`start − rate·days` instead — a different formula; see the 2026-08-05 QA.)

### 16:4-5 — the Rambam's worked example (2 Iyar, N = 29)

> יֵצֵא לְךָ אֶמְצַע הָרֹאשׁ קפ"ב מַעֲלוֹת וְכ"ט חֲלָקִים וְל"ז שְׁנִיּוֹת. סִימָנָם קפ"ב כ"ט ל"ז. תִּגְרַע אֶמְצַע זֶה מִש"ס יִשָּׁאֵר לְךָ קע"ז מַעֲלוֹת וְל' חֲלָקִים וְכ"ג שְׁנִיּוֹת... וְאַל תִּפְנֶה אֶל הַשְּׁנִיּוֹת. נִמְצָא מְקוֹם הָרֹאשׁ בְּמַזַּל בְּתוּלָה בְּכ"ז מַעֲלוֹת וְל' חֲלָקִים.

→ Fixture: emtza harosh 182°29'37"; makom harosh 177°30'23" → displayed
**Virgo 27°30'** (177°30').

### 16:9 — latitude bounded at 5°, reached at the quarter-points

> לְעוֹלָם לֹא יִהְיֶה רֹחַב הַיָּרֵחַ יֶתֶר עַל ה' מַעֲלוֹת בֵּין בַּצָּפוֹן בֵּין בַּדָּרוֹם. אֶלָּא כָּךְ הוּא דַּרְכּוֹ יַתְחִיל מִן הָרֹאשׁ וְיִתְרַחֵק מִמֶּנּוּ מְעַט מְעַט. וְהַמֶּרְחָק הוֹלֵךְ וְנוֹסָף עַד שֶׁיַּגִּיעַ לְחָמֵשׁ מַעֲלוֹת.

→ Latitude grows *continuously* until it reaches 5° (at 90° from the
node). A 5°00' value already at 80° — as the engine shipped before
2026-08-05 — contradicts this narrative directly.

### 16:10 — maslul harochav and its sign

> וְתִגְרַע מְקוֹם הָרֹאשׁ מִמְּקוֹם הַיָּרֵחַ הָאֲמִתִּי. וְהַנִּשְׁאָר הוּא הַנִּקְרָא מַסְלוּל הָרֹחַב. וְאִם יִהְיֶה מַסְלוּל הָרֹחַב מִמַּעֲלָה אַחַת עַד ק"פ. תֵּדַע שֶׁרֹחַב הַיָּרֵחַ צְפוֹנִי. וְאִם הָיָה הַמַּסְלוּל יֶתֶר עַל ק"פ תֵּדַע שֶׁרֹחַב הַיָּרֵחַ דְּרוֹמִי.

### 16:11 — moon latitude table (implemented in `MOON_LATITUDE_TABLE`)

> וְכַמָּה הִיא מְנַת מַסְלוּל הָרֹחַב. אִם יִהְיֶה מַסְלוּל הָרֹחַב עֶשֶׂר מַעֲלוֹת תִּהְיֶה מְנָתוֹ נ"ב חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל הַזֶּה כ' מַעֲלוֹת תִּהְיֶה מְנָתוֹ מַעֲלָה אַחַת וּמ"ג חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל ל' תִּהְיֶה מְנָתוֹ שְׁתֵּי מַעֲלוֹת וְל' חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל מ' תִּהְיֶה מְנָתוֹ שָׁלֹשׁ מַעֲלוֹת וְי"ג חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל נ' מַעֲלוֹת תִּהְיֶה מְנָתוֹ שָׁלֹשׁ מַעֲלוֹת וְנ' חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל ס' תִּהְיֶה מְנָתוֹ אַרְבַּע מַעֲלוֹת וְכ' חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל ע' תִּהְיֶה מְנָתוֹ ד' מַעֲלוֹת וּמ"ב חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל פ' תִּהְיֶה מְנָתוֹ ד' מַעֲלוֹת וְנ"ה חֲלָקִים. וְאִם יִהְיֶה הַמַּסְלוּל צ' תִּהְיֶה מְנָתוֹ ה' מַעֲלוֹת:

→ 10°→52'; 20°→1°43'; 30°→2°30'; 40°→3°13'; **50°→3°50'; 60°→4°20';
70°→4°42'; 80°→4°55'**; 90°→5°0'. Both witnesses agree on every row.

### 16:12 — interpolation rule with the Rambam's own example

> כֵּיצַד. הֲרֵי שֶׁהָיָה מַסְלוּל הָרֹחַב נ"ג מַעֲלוֹת. וּכְבָר יָדַעְתָּ שֶׁאִלּוּ הָיָה הַמַּסְלוּל נ' הָיְתָה מְנָתוֹ שָׁלֹשׁ מַעֲלוֹת וְנ' חֲלָקִים. וְאִלּוּ הָיָה הַמַּסְלוּל ס' הָיְתָה מְנָתוֹ ד' מַעֲלוֹת וְכ' חֲלָקִים. נִמְצָא הַיֶּתֶר בֵּין שְׁתֵּי הַמָּנוֹת ל' חֲלָקִים ג' חֲלָקִים לְכָל מַעֲלָה. וְנִמְצָא לְפִי חֶשְׁבּוֹן מַסְלוּל זֶה שֶׁהוּא נ"ג שָׁלֹשׁ מַעֲלוֹת וְנ"ט חֲלָקִים.

→ **Maslul harochav 53° → 3°59'.** This worked interpolation *requires*

the pre-2026-08-05 engine values. Pinned in
